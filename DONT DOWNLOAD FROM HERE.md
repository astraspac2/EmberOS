# Don't download from here

This page is the **source code** of EmberOS, not the operating system. The green **Code** button and *Download ZIP* give you the files used to build it, which you can't install or boot.

## Want to install EmberOS?

Download the ready-made ISO from the **[latest release](../../releases/latest)**:

1. Open the [latest release](../../releases/latest).
2. Download **EmberOS.iso** (1.8 GB).
3. Write it to a USB stick and boot from it. The release page explains how.

## Want to build it yourself or read the code?

You're in the right place. See the [README](README.md).
